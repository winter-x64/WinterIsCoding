# ❄️ WinterIsCoding for Zed Editor

A cold-toned modern theme family for the [Zed](https://zed.dev) code editor.

---

## 🎨 Themes Included

All 8 canonical WinterIsCoding variants are available:

1. **`WinterIsCoding [OG]`** — Multi-layer panel depth with midnight dark `#181818` canvas.
2. **`WinterIsCoding [OG] Flow`** — Borderless single-sheet canvas (`#00000000` boundaries).
3. **`WinterIsCoding [OG] Zone`** — Framed focus zones with crisp `#282828` borders.
4. **`WinterIsCoding [OG] Zone [no italic]`** — Framed zones with strictly non-italicized typography.
5. **`WinterIsCoding [New] Midnight OLED`** — Pure black `#000000` surfaces for OLED displays.
6. **`WinterIsCoding [New] Frost Light`** — Crisp blizzard light theme with slate and ice-blue accents.
7. **`WinterIsCoding [New] Focus Mode`** — Obsidian Monolith (`#0D1117`) background with GitHub dark borders.
8. **`WinterIsCoding [New] Ergonomic Preview`** — Arctic Mint strings (`#5EEAD4`) and boosted AA contrast keywords (`#818CF8`).

## 📦 Installation

### Option 1: Direct JSON Theme File (Recommended)

1. Copy [`winteriscoding.json`](./themes/winteriscoding.json) into your Zed themes directory:
   - **macOS / Linux**: `~/.config/zed/themes/`
   - **Windows**: `%APPDATA%\Zed\themes\` (or `C:\Users\<username>\AppData\Roaming\Zed\themes\`)
2. Open Zed.
3. Open the Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`), select **`theme selector: toggle`**, and choose your favorite **WinterIsCoding** variant.

### Option 2: Install as a Dev Extension

1. Open Zed.
2. Open the Command Palette (`Cmd+Shift+P` / `Ctrl+Shift+P`) and choose **`zed: extensions`**.
3. Click **"Install Dev Extension"** in the top right.
4. Select the `extras/zed/` folder from this repository.
5. Select any of the **WinterIsCoding** variants in the theme selector!
